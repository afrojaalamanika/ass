
# FitLog – Workout Planner

FitLog is a workout planning website that helps users explore exercises and organize their daily workout routine. This project was built with Next.js and React to practise working with API data and managing workout plans.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI

## Key Features

1. **Explore Workouts:** Browse different exercises and check their details.
2. **Save Workouts:** Save exercises to a separate list for later.
3. **My Plan:** Add workouts to a daily plan with a limit of five exercises.
4. **Track Progress:** Mark workouts as completed.
5. **Sort Workouts:** Sort exercises by duration, calories burned, or rating.
